# {{SUBJECT_NAME}} output

Study artifacts produced by the **{{SUBJECT_NAME}}** tutor (and any other subject-scoped study agent). The tutor writes here and nowhere else in this subject.

```
out/
└── YYYY-MM-DD-short-topic.md   # cheat sheets, reviews, worked practice, notes
```

Anki decks and similar exports use the same naming with a matching extension (`.csv`, `.txt`).

## Conventions

- **Keep it flat.** Do not invent subfolders unless a later agent needs a dedicated type.
- **Date first.** Files are named `YYYY-MM-DD-short-topic.ext` so they sort chronologically.
- **kb stays read-only.** Recaps and cheat sheets live here. They never go back into `kb/`.
- **Safe to delete.** Everything in here can be regenerated by asking the tutor again. `tools/regenerate.py` does not touch this folder.

## How it gets used

Ordinary Q&A stays in chat. The tutor writes a file here when you ask it to save or export something, or when the request *is* a document (a cheat sheet, a one-page review, Anki cards, a worked practice set).

If the assistant cannot write files (for example a ChatGPT custom GPT), it will paste the artifact in chat and tell you the filename to save under this folder.
